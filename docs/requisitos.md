# Requisitos

## Requisitos funcionais

| ID | Requisito |
| --- | --- |
| RF01 | O sistema deverá permitir que o usuário entre no chat informando seu nome. |
| RF02 | O sistema deverá permitir que os usuários enviem mensagens de texto. |
| RF03 | O sistema deverá distribuir as mensagens enviadas para todos os usuários conectados ao chat. |
| RF04 | O sistema deverá exibir as mensagens recebidas em tempo real, sem a necessidade de atualizar a página. |
| RF05 | O sistema deverá informar quando um usuário entrar ou sair do chat. |

## Requisitos não funcionais

| ID | Requisito |
| --- | --- |
| RNF01 | A interface deverá ser simples, intuitiva e de fácil utilização. |
| RNF02 | A comunicação entre cliente e servidor deverá utilizar WebSocket. |
| RNF03 | O sistema deverá permitir a comunicação simultânea entre vários usuários conectados. |
