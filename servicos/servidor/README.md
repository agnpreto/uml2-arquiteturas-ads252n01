# Serviço Servidor - SmartChatz

Este componente será responsável pelo gerenciamento da comunicação do sistema SmartChatz.

## Responsabilidades

- Receber as mensagens enviadas pelos usuários.
- Distribuir as mensagens para os demais usuários conectados.
- Gerenciar as conexões dos participantes.
- Informar quando um usuário entrar ou sair do chat.

## Tecnologias previstas

- Node.js
- Socket.IO
- WebSocket

## Comunicação

O servidor utilizará comunicação em tempo real para receber e distribuir mensagens entre os clientes conectados.
