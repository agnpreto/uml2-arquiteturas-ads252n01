# Serviço Cliente - SmartChatz

Este componente será responsável pela interface de comunicação entre os usuários e o servidor do SmartChatz.

## Responsabilidades

- Permitir que o usuário informe seu nome para entrar no chat.
- Exibir as mensagens enviadas e recebidas.
- Permitir o envio de mensagens de texto.
- Atualizar a conversa em tempo real.
- Informar quando outros usuários entrarem ou saírem do chat.

## Tecnologias previstas

- HTML
- CSS
- JavaScript
- Socket.IO Client

## Comunicação

O cliente se conectará ao servidor utilizando Socket.IO, permitindo enviar e receber mensagens em tempo real sem precisar atualizar a página.
